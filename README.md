# Neon Odyssey — Roll20 Character Sheet

A Roll20 character sheet for **Neon Odyssey**.

## Installation

1. Open your Roll20 Character Sheet settings.
2. In the **HTML** section, paste the **connector HTML** provided in this repository.
3. Inside the connector, find the marked comments:
   - `PASTE page1.html CONTENT HERE`
   - `PASTE page2.html CONTENT HERE`
   - `PASTE page3.html CONTENT HERE`
4. Copy the contents of each corresponding HTML file into its marked location.
5. In the **CSS** section, copy the contents of `sheet.css` **without any changes**.

That's it. The character sheet should then work in Roll20.
